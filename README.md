Mealkart – School Meal Ordering System

Developed a full-stack food ordering platform for school students 
to select and manage meal plans (daily, weekly, monthly)
Built dynamic ordering and cart workflows with real-time state 
management for seamless user interaction
Integrated payment gateway using Razorpay (test mode) to simulate 
secure online transactions
Implemented authentication with OTP-based verification flow 
(development-mode simulation)
Designed backend APIs using Node.js and Express for handling orders,
users, and payment logic
Utilized Supabase for database management and user data handling
Streamlined the meal ordering process, reducing manual coordination 
between parents and school

Tech Stack: React.js, Node.js, Express.js, Supabase, JavaScript
